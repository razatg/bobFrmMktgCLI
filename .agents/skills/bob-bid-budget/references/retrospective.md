# Review recorded predictions

Use `./bob decision review <id> --source <exact-window processed CSV>`. Observe complete days after execution for the recorded duration, then allow conversions to mature. Sum cost and conversions across networks before deriving CPI/CPA.

Return supported, contradicted or inconclusive against the recorded prediction. Missing evidence, immature conversions, partial execution or confounders make the review inconclusive. Association is not causation.

The legacy retrospective no longer emits its unreliable working/not-working verdict. Without a recorded prediction, a legacy plan cannot be graded from its action name. Never manufacture predictions retrospectively.
